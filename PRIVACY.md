# Privacy Policy – AI Content Generator

_Last updated: October 6, 2026_

AI Content Generator is a personal tool used by its owner to create short videos and upload them to the owner's own YouTube channel. It is not offered to other users.

**What it accesses.** With the owner's permission, the app uses the YouTube Data API scope `youtube.upload` only to upload videos to the owner's channel. It does not read, collect, or store anyone else's data.

**What it stores.** The OAuth token is stored privately by the owner (on their computer and as an encrypted GitHub Actions secret) and is used only to upload videos. No data is sold or shared with third parties.

**Revoking access.** Access can be removed at any time at https://myaccount.google.com/permissions.

**Google API Services.** The app's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Contact.** Open an issue at https://github.com/aramboi4/AI-Content-Generator/issues.
